# 🏏 クリケットルールブック

2026年アジア大会（愛知・名古屋）のクリケットT20競技を観戦しながら、リアルタイムでルールを確認できるWebアプリです。

## 🌐 デモ

GitHub Pages: `https://<username>.github.io/cricket-rules-app/`

## ✨ 特徴

- 🔍 **クイック検索** — キーワードでルール・用語を横断検索
- 📖 **カテゴリ別ルール解説** — 基本ルールからDLS方式まで9カテゴリ
- ❓ **「今何が起きた？」** — 試合中の状況からルールを逆引き
- 📝 **用語集** — 55語以上の日英対照辞典
- 🏆 **アジア大会2026情報** — 日程・会場・参加チーム
- ☝️ **審判シグナル図解** — アニメーション付きの視覚的ガイド
- 🌙 **ダーク/ライトモード** — OS設定に自動追従 + 手動切替
- 📱 **モバイル最適化** — スマホ片手操作に対応した下部タブバー

## 📱 対象フォーマット

**T20（Twenty20）** — アジア大会2026で採用されるクリケットの短縮フォーマット

## 🚀 使い方

### ブラウザで直接開く

```
index.html をブラウザで開くだけ！
```

外部依存なし（Tailwind CSS CDNのみ）、オフラインでも利用可能です。

### GitHub Pagesで公開

1. このリポジトリをGitHubにpush
2. Settings → Pages → Source: `main` / `/ (root)` を選択
3. 数分後に `https://<username>.github.io/cricket-rules-app/` でアクセス可能
